# Matumi Software brand

The organisation uses the Matumi brand: a geometric lowercase m crowned with a canopy dot, canopy
green on warm stone, dark first. Wordmarks are always lowercase (matumi, koppel, skakel); running
text keeps the capitals.

## Files

- `assets/Org/matumi-software-avatar.png` (500x500, from the SVG next to it): the organisation
  avatar on GitHub and the company icon elsewhere. The mark in stone `#EDEAE0` and canopy `#549572`
  on char `#161512`. It is full bleed, and the mark stays inside the inscribed circle so a round
  crop does not clip the dot.
- `assets/Logos/matumi-mark.svg`, `matumi-mark-dark.svg`, `matumi-mark-mono.svg`: the mark for light
  grounds, dark grounds and single colour.
- `assets/Logos/matumi-wordmark.svg` and `matumi-lockup-horizontal.svg`: "matumi" in Inter Tight 600
  with the i in canopy. They load the font from the web, so convert the text to outlines before
  using them outside a browser.

## Colour and type

| Token | Light | Dark |
|---|---|---|
| canopy | `#2A6B4E` | `#549572` |
| river | `#2F6F74` | `#5FA0A6` |
| page | `#FBF9F4` | `#161512` |
| ink | `#1C1B18` | `#EDEAE0` |

Inter Tight 600 for the wordmark and display type, Inter for text, IBM Plex Mono for code.

Each product keeps its own brand in its repo under `resources/`. Koppel and Skakel share this
palette with their own marks and Instrument Sans.
