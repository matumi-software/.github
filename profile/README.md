# Matumi Software

We build open tools that connect the machines on your local network.

## Projects

<a href="https://github.com/matumi-software/koppel"><img src="https://raw.githubusercontent.com/matumi-software/koppel/main/resources/design-system/assets/Social/koppel-social-preview.png" alt="koppel" width="420"></a>

**[Koppel](https://github.com/matumi-software/koppel)** shares USB devices across the network.
Plug a device into one machine and use it on another. Linux and Windows, server and client.
GPL-3.0-or-later.

<a href="https://github.com/matumi-software/skakel"><img src="https://raw.githubusercontent.com/matumi-software/skakel/main/resources/design-system/assets/Social/skakel-social-preview.png" alt="skakel" width="420"></a>

**[Skakel](https://github.com/matumi-software/skakel)** is the link between apps on a local
network: finding a server, pairing, signing in, and streaming data. Koppel is built on it. MIT, so
apps of any licence can use it.
